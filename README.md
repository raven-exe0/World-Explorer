# 🌍 World Explorer 🌍

### Explore the world, one country at a time.

World Explorer is an interactive geography website that lets you discover countries around the globe, explore their information, and navigate the Earth through an interactive 3D globe.

🔗 **Live Website:** https://world-explorer-iota-five.vercel.app/

---

## ✨ Features

- 🌎 **Interactive 3D Globe** — Explore the Earth using an interactive globe.
- 🔍 **Country Search** — Find countries quickly and easily.
- 🏳️ **Country Information** — Discover country details, flags, capitals, populations, areas, and currencies.
- 📍 **Geolocation** — Identify your location and explore nearby countries.
- 🌐 **Interactive Maps** — Explore geographical boundaries and country locations.
- 🎨 **Dynamic UI** — Country cards featuring flag-inspired gradients.
- 🚀 **Responsive Design** — Optimized for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- Globe.gl
- GeoJSON
- REST APIs

## 🌌 Design

World Explorer features a dark, space-inspired interface with glowing accents, interactive elements, and a 3D representation of Earth.

The goal is to make geographical exploration more visual, interactive, and enjoyable.
